# Typecast downloads

Installers and update files for [Typecast](https://typecast.pro), the Mac app
that keeps your font library in step across your Macs through your own cloud
drive.

**Download Typecast at [typecast.pro/download](https://typecast.pro/download/).**

This repository only holds release files: no source code. Every installer is
signed by Design Buff LLC and notarized by Apple. Typecast checks this
repository for updates and installs only updates signed with Typecast's own
update key.
